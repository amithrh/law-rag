## Main Product Blockers

1. **Criminal procedure is too generic.**
   Regular bail, anticipatory bail refiling, MCOCA/default bail, medical/interim bail, juvenile in adult jail, unaffordable surety, NDPS quantity, and PMLA pre-arrest questions need variant-specific answer contracts.

2. **Cyber harm needs victim-first variants.**
   Deepfake porn, AI CSAM, morphed images, extortion, political deepfakes, DPDP leaks, stalking, and defamation cannot share one broad cyber answer.

3. **Tribal/caste/state-law colloquial routing is still weak.**
   The system misses or under-serves prompts using words like `baba`, `dadaji`, `patwari`, `bania`, `daayan`, `tonhi`, `ojha`, `Sarna`, `IFR`, and `palli sabha`.

4. **Labour/welfare needs procedural ledgers.**
   Principal-employer wage/accident liability, minimum-wage state notifications, EPF/ESI benefits, ASHA honorarium, scholarships, pensions, and ration-card scheme denials need route-specific document/forum/deadline steps.

5. **Property/civil answer packs are not practical enough.**
   Co-owner sale, ancestral sale without consent, gift deed under pressure, blank thumb impression, will validity, mutation, and passbook issues need better title/proof/forum sequencing.

6. **Street-vendor/local municipal paths are still partial.**
   The route is correct, but seizure, demolition, TVC certificate, zone allotment, panchayat licence, and local fine questions need more practical next steps and local-law caveats.

7. **Banking/platform freezes are mixed.**
   Wrongful debit and some fraud rows passed, but account/fund freezes, education loan denial, gig driver deactivation, and SARFAESI latency need stronger source-specific treatment.

## Claude Review Summary

Claude was used only as a reviewer after the current-branch eval. It did not run tests and did not compare branches.

Review conclusion:

- Do not spend the next pass on broad routing, retrieval, reranker tuning, or latency.
- Route match is already `100%`, expected Act hit is `94.4%`, and p90 latency is inside the current gate.
- The largest defect is that answers are broad-route answers rather than sub-scenario answers.
- The next implementation should add variant-level answer contracts and a colloquial-to-legal vocabulary bridge.
- Prioritize harm-heavy clusters first: criminal procedure, caste/tribal/witch-branding, false-charge/custody, cyber sexual abuse, and child/family emergency paths.

## Next Fix Strategy

Recommended implementation order:

1. Add **variant-level answer contracts** for the top failing routes instead of one answer per broad route.
2. Add a **colloquial-to-legal normalization layer** that maps messy terms into legal variants while preserving the user's own words in the answer.
3. Add **authority ledgers per variant**: controlling Act/section, forum, remedy, deadline, documents, escalation route.
4. Add **citation discipline**: if a required authority is retrieved for a variant, the answer must cite it in the sentence that uses it.
5. Patch source gaps only where the eval proves repeated misses: state minimum-wage notifications, state witch-branding Acts, tribal land/state transfer rules, local vendor/municipal law, and state scheme rules.
6. Keep latency work secondary for now; p50/p90 passed, though max latency still has outliers.
