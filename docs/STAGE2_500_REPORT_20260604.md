## Product Architecture Conclusion

The next real improvement should not be another pile of first-match templates. The architecture needs:

1. **Specificity scoring before template selection.**
   Pick the most specific supported template instead of relying on list order.

2. **Authority ledger enforcement.**
   For each route, define required Act/section/forum/remedy/deadline/document slots and require the answer to cite the slot actually used.

3. **Citation faithfulness gate.**
   Do not count a citation because an Act title appears. Check that the cited passage supports the specific answer sentence.

4. **Per-template precision/recall.**
   Track when each deterministic template fires and whether that row passes product gate.

5. **High-stakes conservative gates.**
   UAPA/default bail, custody, sexual harm, domestic violence, and child-related topics need stricter source and answer checks than ordinary consumer queries.
